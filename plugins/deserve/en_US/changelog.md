# Change Log

## Beta
- Execution of reward actions (goal achieved) and penalty actions (goal missed), in order, with an optional condition per event
- Event backup and redesign of the equipment layout
- "Reset" option for each device, without triggering any adverse actions
- *Deserves* is recalculated when the goal changes
- Scenario keyword selector for actions (message, variable, scenario, etc.)
- New "Percentage of Goal" and "Short" Commands
- Configurable thresholds as a percentage of the target
- Code cleanup and minimum version of Jeedom 4.3
