# Changelog

## Beta
- Merit actions (goal reached) and demerit actions (goal lost) are executed in order, with an optional condition per event
- Events are saved, and the device page layout was redesigned
- “Reset” option per device, without running the demerit actions
- *Is Deserving* is recalculated when the goal changes
- Scenario keyword selector for actions (message, variable, scenario, etc.)
- New “Goal percentage” and “Missing” commands
- Configurable steps as a percentage of the goal
- Code cleanup and minimum version of Jeedom 4.3
